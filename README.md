# 4tact.ru — готовый учебный интернет-магазин автозапчастей

Проект повторяет структуру дизайна: главная страница и страница поиска, но уже с рабочей БД, аккаунтами, корзиной, избранным, заказами, заявками на подбор, админ-панелью и PDF-отчётом.

## Стек

- Python + Flask
- SQLite + SQLAlchemy
- HTML / CSS / JavaScript
- ReportLab для PDF-отчёта

## Запуск Windows

1. Установить Python 3.11+.
2. Открыть PowerShell в этой папке.
3. Создать окружение: `python -m venv .venv`
4. Активировать: `.venv\\Scripts\\Activate.ps1`
5. Установить зависимости: `pip install -r requirements.txt`
6. Запустить: `python app.py`
7. Открыть в браузере `http://127.0.0.1:5000`

## Первый вход администратора

Логин: `admin`
Пароль: `admin`

Смена пароля находится в админке → Профиль.

## Где что находится

- `app.py` — сервер, маршруты API, модели SQLite, авторизация, заказы, заявки, отчёты.
- `templates/` — HTML-страницы.
- `static/css/style.css` — весь внешний вид.
- `static/js/app.js` — общий JS: API, карточки товаров, избранное, корзина.
- `static/uploads/` — загруженные администратором фото товаров.
- `instance/4tact.sqlite3` — база данных; появится автоматически после первого запуска.

## Логика сайта

Покупатель регистрируется по почте и паролю без подтверждения почты. В профиле можно сменить имя, телефон и пароль. В поиске можно искать по строке и фильтрам «Марка / Модель / Искомая запчасть / Бренд». Товар можно добавить в избранное и корзину. Оформление корзины создаёт заявку-заказ со статусом `new`.

«Подбор за вас» требует входа. Пользователь отправляет VIN, искомую запчасть, телефон и комментарий. Заявка попадает администратору со статусом `new`.

Администратор может переводить заказы и заявки в `working` или `done`. Цвета: красный — новое, жёлтый — в работе, зелёный — выполнено. В разделе «Товары» можно создавать, редактировать и мягко удалять товары. При добавлении можно указать до пяти изображений.

В разделе «Отчёт» выбирается период. В отчёт входят все заказы и заявки за период. Итоговая прибыль считается как сумма выполненных заказов (`done`). Кнопка PDF формирует и скачивает отчёт.
